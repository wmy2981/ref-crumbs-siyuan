# 引用面包屑 (Ref Crumbs)

思源笔记插件：在块引用（`((`）搜索列表中显示每个块的**标题层级面包屑**（h2 → h6）。

## 功能

- 在 `((` 块引用搜索列表的每个结果项下方，追加显示该块所在位置的标题层级链，如 `## 标题二 › ### 标题三`
- 标题链与原有 hPath（笔记本/文档树路径）同时保留，视觉上相互区分：
  - hPath：文档树路径（灰色小字，`/` 分隔）
  - 标题链：淡色胶囊样式 + 主题色 `#` 前缀，层级由 `#` 数量表达
- 数据来源：官方 API `/api/block/getBlockBreadcrumb`，无需修改思源内核
- 对加密笔记本自动透传 notebook 参数

## 说明

- 标题层级链仅显示 h2~h6，文档标题（h1）不显示（h1 与文档名重复）
- 搜索列表每次输入都会重建，插件以块 id 定位渲染；请求带有并发限制（4 路）与结果缓存，列表项很多时逐项填充

## 构建

```bash
npm install
npm run build
```

产物在 `dist/` 目录。
