# 引用块搜索列表显示面包屑 (Ref Crumbs)

简体中文 | [English](README.md)

思源笔记插件：在块引用（`((`）搜索列表中，为每个结果块显示其所在的**标题层级链**（h2 → h6）。

## 功能特性

- 在 `((` 块引用搜索列表（`((newFile`、`((newSubDoc` 等提示项之外的每个结果项）中显示标题链
- 标题链与原有 hPath 区分显示：`#` 前缀的数量表达层级（`##`/`###`/`####`），路径与标题链彼此独立
- 标题链仅取 h2 → h6，不显示 h1（文档标题与文档名重复）
- 结果项本身就是标题块时，自动用该标题的文本补全面包屑缺失的末级名称
- 支持加密笔记本（透传 `notebook` 参数，后台 API 与普通笔记本一致）
- 纯前端实现：通过官方 API `/api/block/getBlockBreadcrumb` 取数，不改动内核、不依赖 SQL 权限
- 性能保护：并发限制（4 路请求池）＋ 按块 id 的结果缓存，列表频繁重建时直接复用已获取结果；单块请求失败仅跳过该项，不阻塞后续

## 为什么需要它

思源默认的 `((` 搜索列表只在每个结果项下方显示 **hPath**（笔记本 / 文档树路径），例如：

```
第二轮迭代上线总结
团队笔记/产品/里程碑复盘/
```

但块的具体位置往往藏在文档内部的标题结构里。本插件在 hPath 右侧追加该块所在的**标题层级**面包屑：

```
第二轮迭代上线总结
团队笔记/产品/里程碑复盘/  ## 里程碑复盘 · ### 第二轮迭代
```

从而一眼看出每个引用候选块在文档中的实际章节位置。

## 安装

### 集市安装

在思源集市（设置 → 集市 → 插件）中搜索"引用块搜索列表显示面包屑"或 "Ref Crumbs"，点击安装并启用。

### 手动安装

1. 将本目录（或 `dist/` 内容）放入思源数据目录：`<workspace>/data/plugins/ref-crumbs-siyuan/`
2. 在思源设置 → 插件中启用本插件

## 使用

在任意编辑器输入 `((` 触发块引用搜索，搜索列表的每项下方即可看到标题层级链。无需任何配置。

## 构建

```bash
npm install
npm run build
```

产物位于 `dist/`（含 `package.zip`，可直接用于集市提交）。
